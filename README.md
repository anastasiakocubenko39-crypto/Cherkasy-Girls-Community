# ELARIE — жіночий клуб і журнал Черкас

Сайт жіночої спільноти Черкас: головна, онлайн-журнал (13 рубрик, пошук, читалка статей, калькулятор БЖУ), зустрічі й афіші, сторінка про клуб, дитячі ігри та адмінка.

- `index.html`, `women-journal.html`, `events.html`, `about.html` — сторінки сайту
- `assets/style.css`, `assets/journal.css` — дизайн (білий, рожевий, золото, смарагд, коричневий)
- `assets/site.js` — шапка, меню, футер і анімації появи
- `assets/fb.js`, `assets/journal-data.js`, `assets/journal.js` — дані з Firebase Firestore
- `assets/logo.svg` — логотип ELARIE
- `games.html` — дитяча академія (без змін)
- `admin.html` — адмінка (вхід: 5 натискань на логотип)

Статичний сайт, без збірки. Публікація — GitHub Pages.
